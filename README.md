# AI vs ML vs Deep Learning

## Project Overview

This project compares Artificial Intelligence (AI), Machine Learning (ML), and Deep Learning (DL) using definitions, a comparison table, real-world examples, and an explanation of their relationship.

## Objectives

- Understand the meaning of AI, ML, and DL.
- Compare their features and scope.
- Identify real-world applications.
- Explain how the three concepts are related.

## Features

- Python-generated comparison table
- Definitions of AI, ML, and Deep Learning
- Real-world examples
- Relationship diagram
- Summary and conclusion

## Technologies Used

- Python 3
- Lists and dictionaries
- Functions
- Markdown
- Visual Studio Code
- GitHub

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run:

`python ai_ml_dl_comparison.py`

On Windows, you can also use `py ai_ml_dl_comparison.py`.

No external packages or datasets are required.

## Main Finding

AI is the broader field, Machine Learning is a subset of AI, and Deep Learning is a subset of Machine Learning.

The project provides a clear introduction to AI, ML, and Deep Learning and explains how they differ and relate to one another.
